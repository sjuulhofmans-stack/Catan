# Hexbord (AR-bordspel met beamer)

Een speelbord van zeshoeken voor projectie met een beamer. Het spel wordt fysiek gespeeld; de app visualiseert.

## Lokaal openen
Dubbelklik op `index.html`. Sneltoetsen: **F** = fullscreen, **D** = coördinaten en hoekpunten tonen.

## Online zetten (GitHub Pages)
1. Maak een nieuwe **openbare** repository op GitHub en push deze map ernaar.
2. Ga naar **Settings → Pages**.
3. Kies bij *Source*: **Deploy from a branch**, branch `main`, map `/ (root)`.
4. Na een minuut staat het bord op `https://<gebruikersnaam>.github.io/<repo-naam>/`.
